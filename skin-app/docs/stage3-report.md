## 2. 完成した機能

| 区分 | 内容 |
| --- | --- |
| 分析の流れ | 撮影の保存後「続けて分析する」、または写真一覧の「この撮影で分析する」→ 確認画面 → 分析 → 結果 |
| 確認画面 | 分析する写真、送信先（Anthropic 社 Claude API）・送るもの・目的の説明。「AI に送信して分析する」「AI に送らずに分析する」を毎回選ぶ |
| 撮り直しの判定 | 正面の写真がない・撮影条件を満たさない・判定できない項目が半分以上 → 結果を出さずに撮り直しを案内 |
| 分析結果の画面 | 診断ではない旨とモックである旨を常に表示、撮影条件、顔の図（部位ごとの評価）、見た目の説明、項目×部位の評価と確信度、注意事項、セルフケアの一般情報、医療機関への相談の目安 |
| AI の説明文 | Claude（既定 `claude-opus-5-5`）が写真を見て説明。構造化出力で受け取り、禁止表現（病名・診断・治療・効果の断定・肌年齢・水分量など）を含む文を除去。拒否された場合のフォールバック（`fallbacks: "default"`）を有効化 |
| 安全対策 | AI への送信は、同意（AIサービスへの写真の送信）があり、利用回数の上限内で、本人が確認画面で選んだときだけ。送信を監査ログ（`ai.send`）に記録。氏名・連絡先は送らない |
| 一覧 | 一般ユーザーの「分析」タブ、顧客詳細の「分析」タブ |
| 削除 | セルフは本人、サロンは管理者が分析結果を削除できる（写真は残る） |

## 3. モック・外部 API 未接続の箇所

| 箇所 | 状態 |
| --- | --- |
| 項目ごとの評価（特徴抽出） | **モック**。画像は解析しておらず、写真の ID から決まる仮の値。画面に「モック（未検証）」と常に表示 |
| Claude API との実際の通信 | **未確認**。この開発環境には API キーがないため、送信内容と結果の処理は SDK を差し替えたテストでのみ確認。キーを設定した後に実際の動作確認が必要 |
| AI を使わない場合の説明文 | 仮の定型文（写真は見ていない旨を明記） |
