# 02. 画面設計

> ステータス：**承認済み**（2026-10-03）。実装との差分は [stage2-report.md §5](stage2-report.md#5-設計からの変更点) を参照。

## 1. デザインの方針

### 1.1 色

上質で清潔感のある美容サロン向け。色は CSS 変数（デザイントークン）で定義し、すべての画面で共通にする。

| トークン | 用途 | 色（案） |
| --- | --- | --- |
| `--color-bg` | 画面の背景（アイボリー） | `#FAF7F0` |
| `--color-surface` | カード・入力欄（白） | `#FFFFFF` |
| `--color-text` | 本文 | `#2E2B26` |
| `--color-text-muted` | 補足文 | `#6B655B`（背景とのコントラスト比 4.5:1 以上を確認する） |
| `--color-gold` | 飾り線・強調（シャンパンゴールド） | `#C9B07A`（※文字色には使わない。文字にする場合は濃い `#8A7240`） |
| `--color-sage` | 主ボタン・選択中（セージグリーン） | `#6F8F7A`、濃い色 `#4F6E5A` |
| `--color-border` | 枠線 | `#E8E1D3` |
| `--color-warning` | 再撮影・注意 | `#B5762A` |
| `--color-danger` | 削除・エラー | `#B54A4A` |

- 評価の5段階は「良い／悪い」と感じさせない落ち着いた色の濃淡で表し、**色だけに頼らず数字と言葉も添える**。
- ダークモードは第4段階で対応（トークンを入れ替える方式）。

### 1.2 文字

- 本文 16px、補足 14px（これ未満は使わない）、見出し 20〜28px
- フォント：Noto Sans JP（本文）、見出しのみ Noto Serif JP で上品さを出す（案）

### 1.3 画面の組み立て

| 端末 | レイアウト |
| --- | --- |
| スマートフォン（〜767px） | 1列。主ボタンは画面下部に固定（片手で届く範囲）。下部にタブバー（ホーム／撮影／履歴／記録／設定） |
| タブレット（768〜1199px） | サロン用画面は2列（一覧＋詳細）。撮影はスマホと同じ流れ |
| PC（1200px〜） | 左にメニュー、中央に一覧・表、右に詳細パネルのダッシュボード |

### 1.4 状態の表示（全画面共通）

- 読み込み中：スケルトン表示（枠だけ先に出す）。AI 分析中は手順ごとの進み具合
- 空の状態：次にやることを案内（例：「まだ分析がありません。撮影をはじめる」）
- エラー：何が起きたか・どうすればよいかを日本語で表示。技術的な詳細は表示しない
- AI 未接続／モック：画面上部に帯で常時表示

**撮影から結果までの流れ（スマートフォン）**

```
U-01 ホーム ──[撮影する]──▶ U-02 準備 ──▶ U-03 正面 ──▶ U-03 左 ──▶ U-03 右
                                              │ 品質NG：理由を表示してその場で撮り直し
                                              ▼
                          U-04 確認 ──▶ U-05 AI送信の確認 ──▶ U-06 分析中 ──▶ U-07 レポート
                                              │ 同意しない                 │ 品質不足・判定困難
                                              ▼                            ▼
                                       写真の保存のみ（分析なし）     再撮影の案内 → U-02
```

- 左右の撮影は省略できる（正面だけでも分析できる。ただし部位によっては「判定できず」になる）。
- 各ステップで「戻る」と「中止（写真を保存しない）」を常に選べる。

## 4. アクセシビリティの確認項目

- すべての操作をキーボードで行える。フォーカス位置が見える
- 画像・アイコンに代替テキスト、フォームにラベルとエラー文の関連付け
- 撮影の品質チェックは音声読み上げでも伝わる文言にする（`aria-live`）
- タップ領域は 44×44px 以上
- アニメーションは「視差効果を減らす」設定で止める
- 自動テストに axe（アクセシビリティ検査ツール）を組み込む（第5段階）
