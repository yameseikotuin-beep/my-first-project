# my-first-project

## ダイエット食事管理アプリ

`diet-tracker.html` をブラウザで開くだけで使えるダイエット用の食事管理アプリです。ビルドは不要です。ログインしない場合はブラウザの localStorage のみにデータが保存され、ログインするとクラウド（Firebase Firestore）に保存され、別の端末・ブラウザからも同じアカウントで同じデータにアクセスできます。

### 機能
- パーソナルデータ（性別・年齢・身長・体重・活動量・目標）からBMR/TDEEを計算し、目標カロリー・PFC（たんぱく質/脂質/炭水化物）を自動算出
- 目標値は自動計算後も手動で調整可能
- 朝食・昼食・夕食・間食ごとの食事記録（カロリー、P/F/C）
- 日別のカロリー摂取サマリーと進捗バー、目標PFCとの比較
- 日付を移動して過去の記録を確認・編集
- 直近14日間のカロリー推移グラフ、体重記録と推移グラフ
- ブラウザ内プロフィール切り替え（同じ端末を複数人で使う場合。ログイン中は無効）
- メールアドレス/パスワードでのログインによるクラウド同期（別端末・別ブラウザから同じデータにアクセス可能）

### 使い方（ローカルのみで使う場合）
1. `diet-tracker.html` をブラウザで開く
2. パーソナルデータを入力して「自動計算する」→「この設定を反映する」、または目標値を直接入力
3. 食事を記録し、日々の摂取量を確認

### クラウド同期（別端末からのアクセス）を使う場合のセットアップ

クラウド同期には自分の Firebase プロジェクトが必要です（無料枠で利用できます）。

1. [Firebase コンソール](https://console.firebase.google.com/) で新しいプロジェクトを作成する
2. 「Authentication」→「Sign-in method」で **メール/パスワード** 認証を有効にする
3. 「Firestore Database」を作成する（本番モードでよい）。ルールタブで以下を設定する:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{userId} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```
4. プロジェクト設定（⚙️ → プロジェクトの設定）の「マイアプリ」でウェブアプリを追加し、表示される `firebaseConfig` の値をコピーする
5. `diet-tracker.html` 内の `firebaseConfig` オブジェクト（`var firebaseConfig = { ... }`）を、コピーした値に書き換えて保存する
6. 書き換えた `diet-tracker.html` をブラウザで開くと、画面上部に「☁️ クラウド同期」欄が表示される。メールアドレスとパスワードで「新規登録」し、他の端末・ブラウザでも同じ `diet-tracker.html`（同じ `firebaseConfig` を書き込んだもの）を開いて同じアカウントでログインすればデータが同期される

`firebaseConfig` を書き換えずに開いた場合は「クラウド同期は未設定です」と表示され、従来どおりブラウザ内保存のみで動作します。
