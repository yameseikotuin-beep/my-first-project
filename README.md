# InBody × 痛み因果診断アプリ

InBody計測結果シートの画像をアップロードすると、OCR（Tesseract.js）で数値を自動読み取りし、体の痛みの部位・強さと合わせて、関連しそうな要因の分析と数値に基づく危険度予測を行うブラウザ完結型のHTMLアプリです。

## 使い方

1. `index.html` をブラウザで直接開きます（OCRライブラリをCDNから読み込むため、初回実行時はインターネット接続が必要です）。
2. InBody計測結果の画像をアップロードし、「画像から数値を読み取る」を押します。
3. 自動入力された計測値（体重・BMI・体脂肪率・内臓脂肪レベル・部位別筋肉量など）を確認・修正します。
4. 気になる痛みの部位・強さ・期間を選択します。
5. 「この内容で診断する」を押すと、以下が表示されます。
   - 総合リスク（安全〜危険の4段階）
   - 各計測値の評価（安全/注意/警告/危険）
   - 左右の筋肉量バランス
   - 選択した痛みの部位ごとの関連要因分析
   - 推奨アクション

## 特徴・注意事項

- すべての画像処理・数値解析はブラウザ内（クライアントサイド）で完結し、外部サーバーへデータは送信されません。
- OCRの読み取り精度には限界があるため、自動入力された値は必ず確認・修正してください。
- 本アプリの結果は医学的診断ではなく、あくまで参考情報です。強い痛みや長引く症状がある場合は医療機関を受診してください。

## 技術構成

- 単一の `index.html`（HTML / CSS / JavaScript）
- OCR: [Tesseract.js](https://github.com/naptha/tesseract.js)（CDN経由で読み込み、外部サーバー通信なし）
- 外部フレームワーク不要、ビルド不要
