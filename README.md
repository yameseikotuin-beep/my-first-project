# my-first-project

## ダイエット食事管理アプリ

`diet-tracker.html` をブラウザで開くだけで使えるダイエット用の食事管理アプリです。ビルドやサーバーは不要で、記録したデータはブラウザの localStorage に保存されます。

### 機能
- 1日の目標カロリーの設定
- 朝食・昼食・夕食・間食ごとの食事記録（カロリー、P/F/C）
- 日別のカロリー摂取サマリーと進捗バー
- 日付を移動して過去の記録を確認・編集
- 直近14日間のカロリー推移グラフ
- 体重記録と推移グラフ

### 使い方
1. `diet-tracker.html` をブラウザで開く
2. 目標カロリーを設定
3. 食事を記録し、日々の摂取量を確認
