# my-first-project

React + TypeScript + Vite で作る Web アプリです。

## 必要なもの

- Node.js 20 以上

## セットアップ

```bash
npm install
```

## コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 (http://localhost:5173) |
| `npm run build` | 型チェックと本番ビルド (`dist/` に出力) |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm run lint` | oxlint でコードをチェック |

## ディレクトリ構成

```
src/
  main.tsx   エントリポイント
  App.tsx    メインコンポーネント
  assets/    画像などの静的ファイル
public/      そのまま配信されるファイル
```
