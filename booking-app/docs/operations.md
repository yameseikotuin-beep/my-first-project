# 運用マニュアル（店舗スタッフ向け）

管理画面：`https://（公開URL）/admin`
お客様向け予約画面：`https://（公開URL）/`

管理画面はパソコンでの操作を想定していますが、スマートフォンでも使えます。

---

## 1. ログイン・ログアウト

1. `/admin` を開くとログイン画面が表示される
2. 管理者のメールアドレスとパスワードを入力して「ログイン」
3. 使い終わったら、メニューの下（スマートフォンでは画面の一番下）の「ログアウト」を押す

- 共用のパソコンでは、必ずログアウトしてください。
- パスワードを忘れた場合は、Supabase の Authentication → Users から管理者が再設定します（`docs/setup.md` の 4.）。

## 2. 毎日の確認（ダッシュボード）

ログインすると最初に表示されます。

- **本日の予約件数**：今日の「予約確定」の件数（キャンセルは含みません）
- **本日の予約**：今日の予約の一覧。押すと詳細を表示
- **直近の予約**：これから始まる予約（10件）
- 「予約カレンダー」「各種設定」へのリンク

## 3. 予約の確認

### 予約一覧

- 「予約一覧」で、日付（期間）・ステータス・お名前・電話番号で絞り込めます。
- 電話番号は一部だけでも検索できます（例：`5678`）。
- 「前の日／今日／次の日」で日付を移動できます。

### 予約カレンダー

- 「日別」：施術スペースごとに、その日の予約を時間順に表示します。
- 「週別」：月曜〜日曜の予約を表示します。日付を押すとその日の日別表示に移ります。
- 各予約には、開始・終了時刻、お客様名、メニュー名、施術スペース（週別）、担当施術者（管理している場合）が表示されます。
- キャンセルした予約は初期状態では表示しません。「キャンセルを表示」で点線の枠で表示します。
- 予約を押すと詳細画面に移ります。

## 4. 電話・来店の予約を登録する

1. 「予約を登録」を開く
2. メニューと日付を選ぶと、その日の**空き時間**が表示される。押すと開始時刻に入る
   （一覧にない時刻、例えば 10:05 も直接入力できます）
3. 施術スペース・担当施術者は、通常は「自動で割り当てる」のままでよい
4. お客様のお名前・電話番号・備考を入力し、「この内容で予約を登録する」

- WEB予約と同じく、**ほかの予約と重なる時間・休業日・昼休み・営業時間外には登録できません**。エラーが表示されたら、時間やスペースを変えてください。
- 管理画面からの登録には、「受付可能な期間」「受付締切」「予約枠の間隔」の制限はかかりません（当日の飛び込みにも対応できるように）。

## 5. 予約を変更・キャンセルする

1. 予約一覧・カレンダー・ダッシュボードから予約を押して詳細を開く
2. **変更**：下の「予約内容の変更」で日時・メニュー・スペース・お客様情報を直して「変更を保存する」
   - 変更後の時間に空きがない場合は保存されません（元の予約はそのまま残ります）。
   - お名前・備考だけの修正は、営業時間を後から変えた場合でも保存できます。
3. **キャンセル**：「予約をキャンセルする」→ 確認で「OK」
   - キャンセルした枠はすぐに空きに戻り、WEB予約できるようになります。
   - キャンセルした予約はデータとして残ります（ステータスが「キャンセル」になります）。
4. **キャンセルを取り消す**：詳細画面の「予約ステータス」を「予約確定」にして保存
   - その時間がすでにほかの予約で埋まっている場合は戻せません。

お客様からのキャンセル・変更の連絡は、お電話で受けて管理画面から操作する運用です（お客様自身による WEB 上での変更・キャンセル機能はありません）。

## 6. メニューを管理する

「メニュー」画面で追加・編集します。ソースコードの修正は不要です。

| 項目 | 内容 |
| --- | --- |
| メニュー名・説明 | 予約画面に表示されます |
| 施術時間（分） | 予約の終了時刻と、スペースを使う時間の計算に使います |
| 料金 | 予約画面・確認画面・管理画面に表示されます（オンライン決済はありません） |
| 表示順 | 小さいほど上に表示 |
| WEB予約を受け付ける | オフにすると予約画面に出なくなります。管理画面からは引き続き登録できます |
| 使用できる施術スペース | 「個室でしか行わない」などの場合に選びます。何も選ばなければ全スペースで可 |

- 料金・施術時間を変更しても、**すでに入っている予約の料金・時間は変わりません**（予約時点の内容を保存しています）。
- 予約で使われたメニューは削除できません。受付をやめる場合は「WEB予約を受け付ける」をオフにしてください。

## 7. 施術スペースを管理する

「施術スペース」画面で、ベッドや個室を登録します。

- 同じスペースに時間が重なる予約は入りません。スペースが2つあれば、同じ時間に2件まで予約できます。
- **利用停止**：ベッドの故障などで一時的に使えない場合は、編集画面で「利用可能」をオフにします。そのスペースには新しい予約が入りません（すでに入っている予約はそのまま残るので、必要に応じて変更してください）。
- **利用可能時間**（任意）：特定の曜日・時間だけ使えるスペースは、編集画面で時間帯を登録します。登録がなければ営業時間中いつでも使えます。

## 8. 施術者を管理する（任意）

施術者の人数で予約数を制限したい場合に使います。使わない場合は、施術スペースの空きだけで判定します。

1. 「施術者」画面で「有効にする」
2. 施術者を追加する（利用可能な施術者が1人もいないと、予約を受け付けられません）
3. 施術者の編集画面で、必要に応じて設定する
   - **対応できるメニュー**：選ばなければ全メニューに対応
   - **出勤時間**：曜日ごとの時間帯。登録がなければ営業時間中いつでも対応
   - **休み**：日付単位の休み
   - **利用可能**：オフにすると新しい予約が割り当てられない

- 予約には「空いている施術スペース」と「対応できる空いている施術者」の両方が必要になります。
- お客様が担当者を指定する機能はありません。システムが条件に合う施術者を自動で割り当てます。管理画面から登録・変更する場合は、担当者を指定することもできます。

## 9. 営業時間・休業日を設定する

「営業時間・休業日」画面で設定します。変更はすぐに予約画面へ反映されます。

- **曜日ごとの営業時間**：開始・終了・最終受付。休業日は「休業」にチェック
  - 最終受付：この時刻までに**始まる**予約だけを受け付けます。空欄なら「終了時刻までに施術が終わる」予約を受け付けます。
- **受付停止時間（昼休みなど）**：毎週（曜日指定）または特定の日だけ。この時間にかかる予約は入りません。
- **祝日・臨時休業・特定日の営業時間**：日付ごとに「休業」または「この日だけの営業時間」を設定します。曜日の設定より優先されます。
  - 祝日は自動では休みになりません。年に一度、翌年の祝日をまとめて登録してください。

> すでに予約が入っている日を休業日にしても、その予約は自動ではキャンセルされません。予約一覧で確認し、お客様へ連絡のうえキャンセルしてください。

## 10. 予約受付の設定

「予約受付の設定」画面で設定します。

| 項目 | 初期値 | 内容 |
| --- | --- | --- |
| 店舗名 | 整骨院 | 予約画面の上部に表示 |
| 店舗の電話番号 | （空） | 予約画面の下部に「変更・キャンセルの連絡先」として表示 |
| 予約枠の開始間隔 | 15分 | 予約画面に表示する開始時刻の間隔（施術時間とは別） |
| 受付可能な期間 | 60日 | 今日から何日先までWEB予約できるか |
| 受付締切 | 60分 | 開始の何分前までWEB予約できるか |
| 1つの電話番号で持てる今後の予約数 | 3件 | いたずら予約の対策 |

## 11. お客様からの問い合わせ

- お客様には予約完了画面で**予約番号**（例：`261103-AB7K`）が表示されます。予約一覧の詳細画面に同じ番号が表示されます。
- 予約完了のメール・LINE 通知はありません。お客様には「予約完了画面を保存してください」とご案内ください。

## 12. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 予約画面で「問題が発生しました」と表示される | Supabase のプロジェクトが一時停止していないか（無料プランは長期間アクセスがないと停止します）。Supabase のダッシュボードで再開してください |
| 予約画面でどの日も選べない | 営業時間がすべて休業になっていないか／受付可能な期間が 0 日になっていないか |
| 空き時間が表示されない | 施術スペースがすべて利用停止になっていないか／施術者管理が有効で、利用可能な施術者がいないか |
| 管理画面にログインできない | メールアドレス・パスワードの確認。アカウントが `admins` に登録されているか（`docs/setup.md` の 4.） |
| 同じ時間に予約が重なっているように見える | 別々の施術スペース（と施術者）に割り当てられていれば正常です。同じスペースに重なる予約はデータベースが拒否するため登録されません |

## 13. 個人情報の取り扱い

- 予約画面で集めるのは、お名前・電話番号・備考（任意）だけです。
- 管理画面の情報（お客様の氏名・電話番号）は、ログインした管理者だけが見られます。
- 予約データを書き出したファイル（バックアップ）は、パスワード付きの場所に保管してください。
- 不要になった古い予約データは、Supabase の Table Editor から削除できます（削除は元に戻せません）。
